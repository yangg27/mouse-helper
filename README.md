# 鼠标助手

Windows 定时模拟鼠标点击与上下滚轮的小工具。**单文件 exe，双击即用，零依赖免安装。**

解决一个很具体的痛点：需要让某个软件「保持活跃」或者「反复刷新」时，得隔几分钟手动点一下、滚一下。这活儿交给它。

```
规则一：每 5 分钟点一次鼠标
规则二：每 5 分钟向上滚一圈、再向下滚一圈
```

## 为什么不用现成的

市面上同类工具要么要装 .NET 运行时，要么塞一堆广告和后台服务，要么按键精灵那种杀毒软件直接报毒。

这个只有 9.8MB，内含全部运行库，**目标机器不需要装 Python 或 .NET**。纯本地运行，不联网、不写注册表、不留后台服务，删掉就是彻底卸载。

## 功能

### 两条独立规则

| 规则 | 默认行为 | 可选 |
|---|---|---|
| 一、定时点击 | 左键单击一次 | 左键 / 右键 / 中键 |
| 二、定时滚动 | 向上 1 格，再向下 1 格 | 上下格数各自独立可调 |

两条规则共用同一节奏，一轮里**先点击、后滚动**。间隔默认 5 分钟，可改成任意值（分 + 秒）。

### 位置：两种模式

- **跟随鼠标**——每轮点鼠标「当时」所在的位置。人在动，它跟着动。
- **锁定坐标**——固定在某个点。鼠标停到目标上，按 `F8` 直接抓取。

> 为什么锁坐标要用快捷键：如果去点「取当前坐标」按钮，鼠标就得移开目标，锁到的就成了按钮的坐标。所以必须能在不移动鼠标的情况下抓取——这就是全局快捷键的由来。

### 全局快捷键

页面上每个操作后面都用括号显示当前绑定的键：

| 快捷键 | 功能 | 说明 |
|---|---|---|
| `F6` | 规则一开关 | 按一下开，再按一下关 |
| `F7` | 规则二开关 | 同上 |
| `F8` | 取当前坐标 | 鼠标停在目标上直接按，无需移开 |
| `F9` | 开始 | |
| `F10` | 停止 | 鼠标被页面"抓住"点不到按钮时的兜底 |

**全部是系统级全局热键**，程序在后台、窗口被遮挡、完全失焦时照样生效。

### 快捷键可自定义

**直接点页面上的括号文字**（比如 `(F6)`），弹出录制框，按下你想要的组合键即可。配置自动保存到 exe 同目录的 `hotkeys.ini`，下次打开还是你的设置。删掉该文件即恢复默认。

注册时做了四层冲突防护：

- 单独的字母 / 数字 → 拒绝（会抢占正常打字）
- 系统保留键 → 拒绝：`Ctrl+Alt+Del`、`Alt+F4`、`Alt+Tab`、`Win+L` 等
- 程序内动作重复 → 拒绝，并指明与哪个动作冲突
- 已被其他软件占用 → 该括号变橙色并带 `⚠`，日志写明原因

### 运行中可实时调规则

程序跑起来后，参数（按键类型、滚动格数、间隔）会锁定防误改——但**规则一、二的开关仍然可以按**（`F6` / `F7`，或直接点开关）。改完立刻生效，不用停止再重开。

### 其他细节

- **测试一次**——不启动定时，先干一次看效果。调位置和格数时比反复开关省事。
- **运行日志**——每轮动作、目标坐标、剩余时间都有记录，附带执行次数统计。
- **防自点**——跟随鼠标模式下，如果光标正停在程序自己窗口上，这一轮自动跳过并提示，不会误点自己。
- **休眠校准**——电脑睡眠唤醒后自动校准节奏，不会把休眠期间缺的次数一次性补发。

## 使用

1. 下载 `鼠标助手.exe`（或解压 zip）
2. 双击打开
3. 打开要用的规则开关
4. 点「开始」，或按 `F9`
5. 要停就点「停止」或按 `F10`

设置锁坐标时：先把鼠标移到目标位置，按 `F8`，再按 `F9`。

## 从源码构建

```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name "鼠标助手" main.py
```

产物在 `dist/鼠标助手.exe`。仓库里附了 `build.bat` 可直接双击构建。

依赖：**仅 Python 标准库**（`ctypes` + `tkinter`），无任何第三方包。

## 技术实现

| 模块 | 做法 |
|---|---|
| 鼠标点击 / 滚轮 | `SendInput` 发送 `INPUT_MOUSE`，失败回退 `mouse_event` |
| 全局热键 | `RegisterHotKey` + 消息循环 |
| 定时精度 | 独立线程 + `monotonic()` 时间轴，非 `sleep` 累加，不漂移 |
| 界面 | tkinter 全自绘控件（开关 / 胶囊 / 步进器 / 细滚动条），规避原生控件丑陋 |

### 两个踩过的坑（写在这里省得别人再踩）

**1. `RegisterHotKey` 必须与消息循环在同一线程**

`RegisterHotKey(None, ...)` 把热键绑定到**调用它的那个线程**，`WM_HOTKEY` 只投递到该线程的消息队列。如果主线程注册、子线程跑消息循环，结果是**注册返回成功、按键也发出去了，但回调永远不触发**——没有任何报错，极难排查。

正确做法是注册、注销、`PeekMessage` 全在同一个线程内执行，跨线程用 `queue.Queue` 投递注册请求。

**2. `keybd_event` 触发不了热键回调**

Python 里用 `keybd_event` 发按键，系统收不到 `WM_HOTKEY`；必须用 `SendInput`。

另外 64 位下 `RegisterHotKey` / `PeekMessageW` / `GetMessageW` 都要显式声明 `argtypes`，否则 `HWND` 指针会被当 32 位截断。

## 已知限制

- 若目标程序以管理员权限运行（任务管理器、部分游戏），本程序也需右键「以管理员身份运行」，否则输入事件无法送达——这是 Windows UIPI 机制的强制隔离，无法绕过。
- 锁屏状态下点击不生效，属系统限制。
- 仅支持 Windows 10 / 11 64 位。
